# 薪动 · 上班鼓励器（增强版）

一个轻巧的 Windows 桌面悬浮工资计数器：把「今天已经挣了多少」按 0.1 秒一次刷新摆在屏幕角落，让时间变成看得见的收入。

> 本仓库是 [WizzenH/xindong](https://github.com/WizzenH/xindong) 的修改版，在原版 1.2.3 基础上增加了三个显示项。
> 原版及其全部代码版权归原作者 WizzenH 所有，本项目遵循同样的 MIT 协议，详见 [LICENSE](LICENSE)。

## 相比原版新增

| 新增项 | 显示内容 | 口径 |
|---|---|---|
| 赚钱速度 | `¥0.0074/秒 · ¥26.67/小时` | 当月日薪 ÷ 班内秒数 |
| 下班倒计时 | `距下班 07:00:00` / `距上班` / `已下班` / `今日休息` | 按设置的上下班时间实时计算 |
| 发薪日 | `距发薪 8 天（11 月 15 日）`，当天显示「今天发薪」 | 每月几号发薪可在设置里改，填 31 时小月按月末算 |

原版已有的功能全部保留：八套配色、65%–100% 透明度、置顶无边框、托盘最小化、登录自动启动、单休/双休与手动标记放假调休。

## 下载与安装

前往 [Releases](../../releases) 下载 `xindong-enhanced-1.2.3-win64.zip`（约 18 MB）。

```
SHA256: bf0fff3ecedcd9c03d97444ee7e5ea30200e2cb72b293732588afbff7d4cd77e
```

1. 解压**整个文件夹**到任意位置，例如 `D:\薪动`
2. 双击其中的 `SalaryMotivator.exe`
3. 右下角出现悬浮窗后，点右上角「设置」填月薪、休息方式、上下班时间、每月发薪日

> 注意：不能只把 `SalaryMotivator.exe` 单独拖出来运行，它需要同目录的 `app` 和 `runtime` 文件夹。

- 免安装，不写注册表安装项，不需要管理员权限
- 内置 Python 3.13 运行时，不用另装 Python
- 卸载：先在设置里关掉开机自启，再删除整个文件夹

## 计算口径

日薪 = 月薪 ÷ 当月标记的工作日数。上班前进度为 0，班内线性连续增长（含午休），下班后封顶日薪，休息日为 0。
不涉及税费、社保、奖金，也不做任何实际薪资结算，纯属上班时的一点心理安慰。

## 隐私

程序**不联网**，不上传任何工资、日历或使用数据，所有计算都在本机完成。
配置保存在 `%APPDATA%\salary-motivator\settings.json`，可直接打开查看。

## 常见问题

- **提示「未知发布者」**：安装包未做代码签名，可先核对上面的 SHA256，确认一致后点「更多信息 → 仍要运行」。
- **杀毒软件报警**：未签名 + 打包运行时（PyInstaller/Tcl）常见的误报，源码完全公开，可自行审查。
- **只有 Windows 吗**：目前仅 Windows 10 / 11 64 位。原版另有 Linux（deb）支持。
- **关掉窗口程序没退出**：点 × 或按 Esc 只是收进托盘，后台继续计数；彻底退出请在托盘图标右键选「退出」。
